# SHG 实验数据格式 v1

## 角度与实验约定

- `angle_deg` 是已经换算好的**入射线偏振角 α**，单位为度；不是半波片电机机械角。导入时不再乘二。
- 当前实验几何记录为反射。检测通道可显式标为 `parallel` 或 `perpendicular`；无法确认时保留 `unspecified`，不会从文件名中的 P/S 自动推断。
- 不限制角度范围，不按 180° 或 360° 取模，不自动平均重复角度，不生成闭合点，也不对角度插值。
- 步长只用于逐文件光谱目录，**每批必须手动填写，无默认值**。两列、三列文件直接使用已有角度列。
- 本次查阅的旧 SHG 脚本使用编号乘 12°。这是旧脚本的设置，不能当作其他测量批次的步长。

## 入口一：两列角度曲线

CSV、TXT、TSV 均可，支持逗号、制表符或空白分隔。表头可省略；旧表头 `Angle,Intensity` 兼容。下列数值仅为格式示例：

```csv
angle_deg,intensity
0,123
12,157
24,98
```

第一列是入射偏振角，第二列是已从光谱中提取的 2ω 信号强度。强度单位保持输入单位，不自动归一化或扣背景。两通道各导入一份文件。裸两列文件不能证明第二列的提取方式，应另行保留目标波长及处理记录。

## 入口二：三列完整光谱长表

```csv
angle_deg,wavelength_nm,intensity
0,531.8,123
0,532.1,141
12,531.8,157
12,532.1,168
```

一行表示一个角度下的一个光谱采样点；波长单位固定为 nm。每个角度至少有两个不同波长。光谱可以按降序记录，导入后会排序，但同一个角度下的重复波长会报错，不会自动平均。若有重复测量，请按独立光谱文件保存，以免三列格式无法区分测量轮次。

## 入口三：现有逐文件光谱目录

选择一个测量序列目录，目录中每个 TXT/CSV/TSV 文件均为两列 `wavelength_nm, intensity`，可无表头。例如实际命名形式：

```text
0313-1-shg-80-polar--000--Spec.Data 1.txt
0313-1-shg-80-polar--001--Spec.Data 1.txt
```

角度按以下公式生成：

```text
angle_deg = start_deg + sequence * step_deg
```

`start_deg` 是序号 **000** 对应的角度，默认 0°；`step_deg` 必须手动填写，支持小数和负数。不会解释文件名中的其他数字，也不会扫描子目录或混合不同测量序列。

同序号且字节完全相同的副本仅提取一次，并在元数据中列出排除原因和原文件。相同序号、内容不同的光谱作为重复测量保留。文件序号的缺口会提示，测量点不会补齐。

## 光谱取值方法

目标 2ω 波长需按本次实验指定。GUI 中的 532 nm 仅取自旧分析的建议值，不表示已确认本次激发波长。CLI 要求显式指定目标波长。

| 方法 | 定义 | 必须记录的信息 |
|---|---|---|
| `nearest`（默认） | 选取距离目标最近的实测波长点 | 目标波长、实际采样波长、允许偏差 |
| `linear` | 在目标波长处对相邻光谱采样点线性插值 | 目标波长、方法、源文件及允许偏差 |
| `window_max` | 取目标波长 ± 窗口半宽内的最大光谱强度 | 窗口半宽、最大值所在波长 |
| `integral` | 扣背景后，在指定波长窗口内梯形积分 | 窗口、波长边界插值、单位为输入强度×nm |

最近点/插值所用采样点允许偏差默认 0.5 nm，可手动修改；超差、目标超出光谱覆盖范围或信号窗口无采样点均报错。此处插值只作用于单条光谱的波长轴。

默认不扣背景、不平滑、不裁剪负值。可显式设置一个或多个背景波段，例如 `510:525;539:560`，选择常数或线性背景。常数背景使用这些波段内全部实测点的算术平均值。背景波段必须被光谱完整覆盖，且不能与信号所用波段或采样点重叠。负的扣背景结果保留。

指定波长点强度、窗口最大值与积分面积是不同量，两个通道应使用一致方法。2.0 版提供显式积分、常数／线性背景、可选曝光及功率平方修正，并从背景残差传播近似误差。饱和阈值由用户填写，孤立点只提示复核，不自动删点。处理设置与条件性误差模型写入元数据；物理模型及误差边界见 `physics_model.md`。

## 导出及可追溯性

每次导出创建新目录，包含：

- `shg_curve.csv`：严格两列 `angle_deg,intensity`。
- `shg_curve.metadata.json`：角度含义、几何、通道、输入文件绝对路径及 SHA-256、序号映射、提取设置、逐谱所选波长、原始强度、背景值、排除副本及软件版本。

已有导出目录拒绝覆盖，原始输入不修改。重新导入此 CSV 时自动读取同名元数据并校验 CSV 哈希，防止处理记录与数据错配。修改提取参数后必须重新提取才能导出；光谱缩放预览不改变数据和处理设置。

旧分析输出 CSV 中可能包含取模后重复的角度和人为补出的闭合点。这类 CSV 导入时会原样保留；需要来源明确的数据时，建议由原始光谱重新提取。

## 运行

GUI：

```powershell
python src/run_experimental_import.py
```

命令行与 GUI 调用同一计算模块。以下示例使用旧批次确认的 12° 偏振角步长及旧目标波长，实际运行时应替换为本次实验设置与新的输出目录：

```powershell
$seriesPath = 'D:/SHG数据/样品1/平行通道'
python src/import_shg_data.py $seriesPath --kind folder --step-deg 12 --start-deg 0 --target-nm 532 --method nearest --output './exports/first_run'
```

其他入口分别使用 `--kind curve` 或 `--kind table`。背景区间可重复指定，例如 `--background 510 525 --background 539 560`。窗口最大值示例为 `--method window_max --half-width-nm 1`。只有检测通道已确认时，才加入 `--channel parallel` 或 `--channel perpendicular`。
