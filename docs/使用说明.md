# SHG 实验分析 2.0：鼠标操作说明

这是供 Windows 64 位使用的独立程序。下载并双击 `SHGWorkbench-2.0.0.exe`，无需安装 Python。不要用旧版 `SHGSimulator.exe` 判断本版功能。

## 第一次使用

1. 打开程序，选择“2. 联合拟合与报告”。
2. 点击“载入模拟示例”，再点“开始联合拟合”。这是有明确标签的模拟数据，设定取向为 17.3°，用于熟悉操作，不能当作实验结果。
3. 查看右侧图样、残差、“参数与可信范围”和“模型、标定与完整结果”。
4. 点击“导出图、参数、残差和报告”，选择保存位置。软件会创建新的文件夹，里面的 `report.html` 双击即可阅读。

## 导入真实数据

### 已有两列角度曲线

在分析页分别点击“载入 ∥ 两列曲线”和“载入 ⊥ 两列曲线”。格式为 `angle_deg,intensity`，CSV、TXT、TSV 均可，有无表头都支持。角度是**已经换算好的入射偏振角，单位为度**，不会再乘二。

两通道必须使用可比较的强度：同一种光谱提取方式、相容的强度单位，以及适当的曝光时间和通道响应修正。软件不会把两通道各自归一化到 1。

### 每个角度一条光谱，或三列原始长表

1. 选择“1. 导入与光谱”。
2. 选择输入形式：三列“角度、波长、强度”，或“目录：每个序号一条光谱”。
3. 选择一个测量序列文件夹；逐文件数据应是“波长 nm、强度”两列，文件名含 `--000--`、`--001--` 等序号。
4. **目录模式的步长必须手动填写，没有默认值**。起始角是序号 000 的角度。软件按“起始角＋序号×步长”生成偏振角，支持小数和负步长。已有角度列的文件不使用步长。
5. 根据实验设置目标 2ω 波长。通常为激发波长的一半；界面中的 532 nm 只是旧分析留下的建议值，请核实本次实验。
6. 选择最近实测点、目标波长插值、窗口最大值或积分面积。峰高与积分面积是不同物理量，两通道应一致。
7. 如需扣背景，在峰外填写背景区间，例如 `510:525;539:560`。可选常数或线性背景；留空时不扣背景。窗口与背景不能重叠。
8. 若曝光时间不同，可填写曝光秒数，程序会除以曝光时间。按功率平方修正仅适用于束斑、脉宽、重复频率等条件保持不变的测量；没有可靠功率记录时留空。
9. 若知道探测器满量程，填写原始强度的饱和阈值。软件只提示，不自动删点或平滑。
10. 点击“导入／提取并预览”，逐条查看原谱、目标采样点、信号窗口和背景。可切换目标附近与完整光谱视图。
11. 点击顶部“用作平行通道”或“用作垂直通道”，再导入另一通道。

角度不会取模、补闭合点或插值；重复测量保留。同序号且字节完全相同的副本会被列入处理记录；不同内容的同序号光谱保留为独立记录。序号缺口会提示。原始文件只读。

## 拟合设置

- **点群需要按样品薄片／表面的有效对称性选择**。材料未知时，不要把六瓣图样当作软件已判定材料的证据。中心对称体材料也可能有表面或其他机制的 SHG，本程序的零体电偶极张量不能用于否认这些信号。
- 默认几何是接近正入射；输入实际入射角，选择检偏器同步旋转或固定角度。固定检偏器模式下，两路代表两个正交检测方向，不再等同于随入射偏振定义的 ∥/⊥。
- 不确定实验零点时，取向只能相对于本次零点解释；不要勾选“已经标定”。
- 通道响应比是相同 SHG 强度在垂直与平行检测链路中的读数之比，默认 1 是假设，不是已完成标定。只有有依据时才勾选已标定。
- “独立分量”表中的值是固定张量比，或高级拟合的初值，不是内置材料常数。修改独立分量后，关联分量自动满足点群和 SHG 指标交换对称性。
- 可先固定合理的张量比，只拟合取向、强度比例和两路偏置。高级模式可以拟合可观测张量比，参考分量固定为 1；复数模式还固定了整体相位参考。
- 参考分量应当非零且可观测，可在下拉框中手动选择。“张量比绝对值上限”的默认 10 只是数值搜索设置，不是材料定律。触及边界时不输出区间；可调整参考分量或上限，重新检查拟合。
- 若提示参数不能唯一辨识，应减少自由参数或固定取向。软件会保留曲线拟合，但不提供虚假的参数可信区间。
- 积分误差可由背景残差近似传播；没有完整逐点误差时使用等权拟合。95% 区间依赖所选模型和噪声假设，不包含所有标定与系统误差。

## 基底反射修正

没有光学常数时可用“相对图样”模式分析取向与图样，不能从任意探测器计数反推出绝对 χ。

若有可靠数据，可选择“薄片／单一半无限基底”，或“薄片／介质膜／基底”。例如硅片上可能有氧化层，只有实际存在且厚度已知时才选介质膜模型。分别填写激发频率与二倍频处的复折射率 `n+kj`、膜厚和来源；不同波长的折射率不能混用。估计值必须在来源栏注明。

本模型适用于面内电偶极薄片、各向同性线性基底和近正入射平面波近似。强聚焦高 NA、显著面外响应、基底自身的 SHG、各向异性多层介质及相干多来源干涉需要其他模型；拟合良好不能证明这些机制不存在。

## 检查与保存

- 点击“测量质量与排除”查看逐点提示。孤立像素提示也可能来自真实窄峰，请查看原谱后决定。只有手动勾选且填写原因的点才会被排除。已知饱和点需明确排除或重新采集。
- 默认重采样 100 次；可以取消运行。残差应围绕零分布，若出现有规律的角度依赖，应重新检查材料模型、光学配置与数据处理。
- D3h 等模型存在 60° 等价取向，软件列出等价角。跨周期可信区间按展开角解释，不能把等价解当成不同晶畴。
- “保存项目”保存已提取曲线、参数与来源记录，之后用“打开项目”继续分析。它不复制原始光谱，不代替原始数据备份。重新查看原谱需要相应源文件。
- “导出报告”会保存图像 PNG/PDF、参数 CSV、数据与残差 CSV、完整结果 JSON、可重新打开的项目及 HTML 报告。每次创建新文件夹，不覆盖以前的分析结果。

## 遇到问题

- 没有目标波长：检查波长单位、激发波长和文件类型；不要把拉曼位移当成 nm。
- 要求填写步长：目录模式不会猜测步长，请查本批记录；两列／三列角度数据可直接导入。
- 无可观测信号：检查所选点群是否适合薄片／表面及面内几何；不要任意增添张量分量来让拟合变好。
- 参数不唯一：减少张量自由度，使用已知取向或增加独立测量信息。增加拟合次数不能解决物理上的不可辨识。
- 程序错误：如弹出错误记录路径，可将该文件与复现操作交给维护者。软件日志保存在本机用户目录，不自动上传实验数据。
